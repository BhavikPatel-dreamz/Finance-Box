# WordPress setup

The current WordPress site is [Finance](https://web3.dddemo.net/wordpress/2026/finance). Its GraphQL endpoint is [https://web3.dddemo.net/wordpress/2026/finance/graphql](https://web3.dddemo.net/wordpress/2026/finance/graphql).

## Required before pages can render from the CMS

- WordPress 6.4+ on PHP 8.1+
- Pretty permalinks
- WPGraphQL
- ACF Pro
- WPGraphQL for ACF
- The Financebox Headless plugin, already installed on that server

Flexible Content is an ACF Pro field. The Page Builder group is already registered on the external site. This repository does not contain WordPress files.

After import, confirm in GraphiQL that a page exposes `pageBuilder { pageSections { __typename } }`. The layout type name is generated by WPGraphQL for ACF. The contact section matches type names ending in `ContactForm`. If the live name differs, update `matchesType` and record the real name in `agent.md`.

## Plugin settings

Settings → Financebox:

- Frontend URL, for example `http://localhost:3000`
- Revalidate secret, the same value as `REVALIDATE_SECRET`
- Form secret, the same value as `CONTACT_FORM_SECRET`

Assign menus to the Primary and Footer locations. WPGraphQL exposes those locations as the enum values `PRIMARY` and `FOOTER` when the plugin is active. The frontend checks the live enum before querying a menu.

## SEO

Core title, the plain text of `content`, featured image, and a canonical URL on `NEXT_PUBLIC_SITE_URL` are used for metadata. This site's `Page` type does not expose `excerpt` or `seo` yet.

When the WPGraphQL Yoast SEO Addon is activated later, the page query also reads `seo.title`, `seo.metaDesc`, `seo.canonical`, `seo.opengraphTitle`, `seo.opengraphDescription`, and `seo.opengraphImage.sourceUrl`. Those values replace the core metadata when they are present. Rank Math uses a different GraphQL shape and is not mapped.

## Preview

`/api/preview?secret=<PREVIEW_SECRET>&id=/page-uri/` enables draft mode. `WORDPRESS_PREVIEW_USER` and `WORDPRESS_PREVIEW_PASSWORD` stay on the server and are sent as Basic auth. `/api/preview/exit` leaves preview. Preview HTML is marked `noindex`.
